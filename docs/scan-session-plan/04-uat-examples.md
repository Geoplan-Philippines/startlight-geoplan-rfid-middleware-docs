# UAT examples

## In plain terms

Give me safe documents that can be sent to UAT. I will use them to capture real, copyable requests and responses.

## Provide

One example for each flow:

| Flow | Document reference needed |
| --- | --- |
| Goods Receipt | Purchase Invoice |
| Goods Delivery | Sales Order |
| Customer Returns | Credit Note |
| Vendor Returns | Debit Note |

Each example needs:

- Expected SKU lines and quantities.
- EPC values already mapped to those SKUs in Geoplan.
- Reader ID used for the test.
- Expected successful outcome.

Use synthetic or approved UAT data. Do not send production customer data or credentials.
