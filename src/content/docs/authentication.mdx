---
title: Authentication
description: API key authentication for the Geoplan RFID middleware integration.
---

API key is the authentication scheme across the integration. Every authenticated request carries an `x-api-key` header.

## Keys

| | |
| --- | --- |
| Issued by | Geoplan. Request a key from your Geoplan contact. |
| Expiry | Never expires. |
| Use | Send on every authenticated request. |
| Handling | Treat as a secret — don't commit it or embed it in client code. |

## Request

Base URL `https://rfid-middleware.geoplanph.com/api/v1` (host not yet provisioned — confirm with Geoplan).

```http
GET /api/v1/master-data-sync HTTP/1.1
Host: rfid-middleware.geoplanph.com
x-api-key: <key issued by Geoplan>
```

```bash
curl "https://rfid-middleware.geoplanph.com/api/v1/master-data-sync" \
  -H "x-api-key: <key>"
```

## Missing or invalid key

Returns `401 Unauthorized`. The request is not processed.
