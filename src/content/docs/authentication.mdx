Every request carries an `x-api-key` header. No key, or an unknown key, gets a `401` and the request isn't processed. Applies to **every** endpoint in this reference.

```http
GET /api/v1/scan-activities HTTP/1.1
Host: rfid-middleware.geoplanph.com
x-api-key: rfid_AbC…WRGkU
```

```bash
curl "https://rfid-middleware.geoplanph.com/api/v1/scan-activities" \
  -H "x-api-key: rfid_AbC…WRGkU"
```

## Keys

Geoplan issues your key before you start integrating. Format: `rfid_` prefix + random token, e.g. `rfid_AbC…WRGkU`.

Treat it as a secret. Don't commit it or embed it in client code. If it's compromised, ask Geoplan to rotate it.

<Aside type="caution">Base URL `https://rfid-middleware.geoplanph.com/api/v1` is not yet provisioned. Confirm with Geoplan before integrating.</Aside>
