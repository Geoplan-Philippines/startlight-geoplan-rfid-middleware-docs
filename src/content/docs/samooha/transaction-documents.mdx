---
title: Transaction Documents
description: Samooha ingest of GRN, CRN, GD, and VRN documents, and the GRN result post back to Samooha.
---

Samooha POSTs GRN, CRN, GD, and VRN documents to Geoplan in batches. A warehouse user on the Geoplan app picks a document and starts the scan. Geoplan POSTs scan results back only for GRN.

## Process flow

| Step | Actor | Action |
| --- | --- | --- |
| 1 | Samooha | POST GRN, CRN, GD, and VRN documents in batches. |
| 2 | Warehouse user | Pick a document on the Geoplan app and start the scan. |
| 3 | Geoplan | POST scan results to Samooha only for GRN. |

## Ingest

```http
POST https://api-stg-sling.rgoc.com.ph/api/v1/transaction-documents
x-api-key: <api-key>
Content-Type: application/json
```

Request body:

```json
{
  "documents": [
    {
      "activity": "GRN",
      "documentNumber": "PI-26084567",
      "documentReference": "ASN-8891",
      "partnerName": "On Running - SSI",
      "warehouseCode": "WH01",
      "lines": [
        {
          "sku": "RP80282244",
          "quantity": 100
        }
      ]
    }
  ]
}
```

### Source fields

| activity | documentNumber | documentReference | partnerName |
| --- | --- | --- | --- |
| GRN | PI Doc # | PI Ref # | Vendor Name |
| CRN | CN Doc # | CN Ref # | Customer Name |
| GD | SO Doc # | SO Ref # | Customer Name |
| VRN | DN Doc # | DN Ref # | Vendor Name |

There is no `lineNumber`. One line per SKU. `quantity` is expected scan qty, not scanned qty.

## Goods Receipt result

Geoplan posts the scanned result to Samooha. Spec: [Samooha RFID API](https://rmk.samooha.com/docs/v1/).

```http
POST /rfid/grn
X-API-KEY: <api-key>
Content-Type: application/json
```

```json
{
  "documentRef": "<document-reference>",
  "lines": [
    {
      "sku": "RP80282244",
      "quantity": 100
    }
  ]
}
```

Success: `204`.
