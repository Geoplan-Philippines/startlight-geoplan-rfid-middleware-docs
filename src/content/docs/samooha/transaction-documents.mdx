---
title: Transaction Documents
description: Samooha ingest of GR, CR, GD, and VR documents, and the GRN result post back to Samooha.
---

Samooha POSTs documents to Geoplan in batches. A warehouse user on the Geoplan app picks a document and starts the scan. Geoplan POSTs scan results back only for GRN.

## Process flow

| Step | Actor | Action |
| --- | --- | --- |
| 1 | Samooha | POST documents in batches. |
| 2 | Warehouse user | Pick a document on the Geoplan app and start the scan. |
| 3 | Geoplan | POST scan results to Samooha only for GRN. |

## POST documents

```http
POST https://api-stg-sling.rgoc.com.ph/api/v1/transaction-documents
x-api-key: <api-key>
Content-Type: application/json
```

Request body:

```json
{
  "documents": [
    {
      "activityCode": "GR",
      "documentReference": "ASN-8891",
      "lines": [
        {
          "sku": "RP80282244",
          "quantity": 100
        }
      ]
    }
  ]
}
```

### Source fields

| activityCode | documentReference |
| --- | --- |
| GR | PI Ref # |
| CR | CN Ref # |
| GD | SO Ref # |
| VR | DN Ref # |

`activityCode` is maintenance `activityCode`: `GR`, `GD`, `VR`, `CR`. [Scan Activities](/samooha/scan-activities/) lists `GOODS_RECEIPT`, `GOODS_DELIVERY`, `CUSTOMER_RETURNS`, `VENDOR_RETURNS`. No mapping in this contract.

There is no `lineNumber`. One line per SKU. `quantity` is expected scan qty, not scanned qty.

Response body:

```json
{
  "statusCode": 201,
  "message": "Success",
  "data": {
    "documents": [
      {
        "activityCode": "GR",
        "documentReference": "ASN-8891",
        "status": "New"
      }
    ]
  }
}
```

## Status

Allowed values: `New`, `In-Progress`, `Completed`, `Failed`.

## Goods Receipt result

Geoplan posts the scanned result to Samooha. Spec: [Samooha RFID API](https://rmk.samooha.com/docs/v1/).

```http
POST /rfid/grn
X-API-KEY: <api-key>
Content-Type: application/json
```

```json
{
  "documentRef": "<document-reference>",
  "lines": [
    {
      "sku": "RP80282244",
      "quantity": 100
    }
  ]
}
```

Success: `204`.
