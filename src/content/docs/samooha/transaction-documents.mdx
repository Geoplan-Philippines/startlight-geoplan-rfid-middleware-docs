---
title: Transaction Documents
description: Samooha ingest of GR, CR, GD, and VR documents, and the GRN result post back to Samooha.
---

Samooha POSTs documents to Geoplan in batches. A warehouse user on the Geoplan app picks a document and starts the scan. Geoplan POSTs scan results back only for GRN.

## POST documents

```http
POST https://api-stg-sling.rgoc.com.ph/api/v1/transaction-documents
x-api-key: <api-key>
Content-Type: application/json
```

Request body:

```json
{
  "activity": "GR",
  "documentNo": "GRN-00001",
  "documentSource": "PI-26084567",
  "refNo": "ORFW26-310003494",
  "whCode": "10000-09",
  "lines": [
    {
      "sku": "RP80282244",
      "quantity": "2"
    }
  ]
}
```

Response:

```json
{
  "statusCode": 201,
  "message": "Success",
  "data": {
    "documents": [
      {
        "activity": "GR",
        "documentNo": "GRN-00001",
        "status": "New"
      }
    ]
  }
}
```

## Goods Receipt result

Geoplan posts the scanned result to Samooha. Spec: [Samooha RFID API](https://rmk.samooha.com/docs/v1/).

```http
POST /rfid/grn
X-API-KEY: <api-key>
Content-Type: application/json
```

Request body:

```json
{
  "documentNo": "GRN-00001",
  "documentSource": "PI-26084567",
  "lines": [
    {
      "sku": "RP80282244",
      "quantity": "2"
    }
  ]
}
```

Response:

```json
{
  "code": "VALIDATION_FAILED",
  "message": "The GRN document is already posted."
}
```
