Samooha is the warehouse (WMS) source. Geoplan syncs its product master so warehouse records and RFID reads resolve to the same SKU.

Geoplan's middleware sync API and auth: see **[Master Data Sync](/master-data-sync/)** and **[Authentication](/authentication/)**. Samooha-specific values below.
