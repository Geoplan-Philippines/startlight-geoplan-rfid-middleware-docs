Samooha scans warehouse processes — goods receipt, stock transfer, cycle count, returns. Each is one scan session: open it under the matching activity, the dock/handheld/gate reader streams EPCs, complete it and post the movement from the returned EPCs.

Core flow and endpoints: **[EPC Scan Processing](/epc-scan-processing/)**. Auth: **[Authentication](/authentication/)**. Samooha specifics below.

## Samooha specifics

| | |
| --- | --- |
| Activities | Create one per process via [Scan Activities](/scan-activities/), e.g. `GOODS_RECEIPT`, `STOCK_TRANSFER`, `CYCLE_COUNT`. Reuse the `id`s. |
| Reader | `deviceId` = the dock / handheld / gate reader's `id` — list via [GET /rfid-readers](/rfid-readers/). |
| `transactionReference` | Delivery / document number. |
| Per scan | `POST /epc-scan-processing/sessions` (activity + reader) → poll → `POST …/complete` → post the movement from the returned `epcs`. |
| Abandon | `POST …/cancel`. |
