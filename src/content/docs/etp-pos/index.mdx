ETP POS is the point-of-sale source. Geoplan syncs its product master so barcode and RFID reads resolve to the same SKU.

Geoplan's middleware sync API and auth: see **[Master Data Sync](/master-data-sync/)** and **[Authentication](/authentication/)**. ETP-specific values below.
