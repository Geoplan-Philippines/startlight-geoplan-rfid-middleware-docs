ETP POS scans at checkout. A cashier **Start** opens a scan session; the lane reader streams EPCs; **Stop** completes it and returns the EPCs, which POS resolves to SKUs and bills.

Core flow and endpoints: **[EPC Scan Processing](/epc-scan-processing/)**. Auth: **[Authentication](/authentication/)**. ETP specifics below.

## ETP POS specifics

| | |
| --- | --- |
| Activity | Create one via [Scan Activities](/scan-activities/), e.g. `POS_SALE`. Reuse its `id` on every session. |
| Reader | `deviceId` = the lane flatbed reader's `id` — list via [GET /rfid-readers](/rfid-readers/). |
| `transactionReference` | POS bill / order number. |
| Start | `POST /epc-scan-processing/sessions` on cashier **Start**. |
| Progress | Poll `GET /epc-scan-processing/sessions/:id` to show the live count. |
| Stop | `POST …/complete` → resolve returned `epcs` → SKUs → bill. |
| Abandon | `POST …/cancel`. |
