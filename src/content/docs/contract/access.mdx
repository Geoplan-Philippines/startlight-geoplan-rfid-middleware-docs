Geoplan connects to each provider using the access method that provider already supports.

## Authentication

There is no Geoplan-mandated authentication header for provider master data. ETP POS and Samooha may use different server-to-server authentication methods. Geoplan configures each connector accordingly.

For each environment, record the provider's supported:

- endpoint, database connection, export location, or other approved read method;
- authentication and credential-rotation process;
- network allowlisting, VPN, or private-connectivity requirements;
- test credentials and production credential ownership.

The provider manages access to its source. Geoplan stores and uses the supplied credentials securely.

## Rate limiting

No shared provider rate limit is imposed by this integration reference. Geoplan follows the limits and availability characteristics of each source.

The source-specific connector accounts for:

- request or query limits;
- timeout behavior;
- retry guidance such as `Retry-After`, when available;
- maintenance windows and expected availability;
- safe polling or export frequency.

These values affect Geoplan's connector configuration; they do not require the provider to change its source API or data model.
