---
title: Scan Activities
description: Look up the business processes RFID scan sessions run under.
---

A **scan activity** is the business process a scan runs under: Goods Receipt, POS Sale, Stock Transfer, Customer Returns, cycle count, and so on. Every [scan session](/epc-scan-processing/) references exactly one **active** activity, so reads are grouped and audited by process.

Activities are set up in the dashboard before you integrate. Use these endpoints to look up the `id` you need for a session. All require [`x-api-key`](/authentication/).

## Base URL

```
https://rfid-middleware.geoplanph.com/api/v1
```

Success responses are wrapped as `{ statusCode, message, data }`. Errors are `{ statusCode, message, error, path, timestamp }`. Rate limit: 100 requests / 60s.

## Fields

| field | type | notes |
| --- | --- | --- |
| `id` | uuid | server-generated. Use on sessions. |
| `code` | string | unique machine key. Upper-cased, spaces become `_`. Pattern `^[A-Z][A-Z0-9_]*$`. ≤ 60. e.g. `GOODS_RECEIPT` |
| `name` | string | display label. ≤ 120. e.g. `Goods Receipt` |
| `description` | string \| null | optional. ≤ 500 |
| `isActive` | bool | default `true`. `false` = archived, not selectable for new sessions |
| `createdAt` / `updatedAt` | ISO-8601 | server-managed |

## GET /scan-activities

List all activities, ordered by `name` asc. Not paginated.

| param | type | notes |
| --- | --- | --- |
| `isActive` | bool | omit for all, `true` returns only selectable ones |

```json
{
  "statusCode": 200,
  "message": "Success",
  "data": [
    { "id": "a2c0b6d4-6f1e-4a3b-8c77-2f9f1d4e5b10", "code": "GOODS_RECEIPT", "name": "Goods Receipt", "description": "…", "isActive": true, "createdAt": "…", "updatedAt": "…" }
  ]
}
```

## GET /scan-activities/:id

Single activity by `id`. `404` if unknown.

## Errors

| status | when |
| --- | --- |
| 400 | Invalid `isActive` param. |
| 401 | Missing or invalid `x-api-key`. |
| 404 | Activity not found. |
| 429 | Rate limit exceeded (100 req/60s). |
